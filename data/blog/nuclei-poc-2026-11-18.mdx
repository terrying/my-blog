### openDCIM - Unauthenticated SQL Injection to Remote Code Execution

- **漏洞ID**: `CVE-2026-28516`
- **CVE**: `CVE-2026-28516` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.0107 (percentile 0.65419) @ 2026-11-17

**描述**: openDCIM through commit 4467e9c4 (tested on v23.04) exposes install.php without a post-installation lock or authorization check. The unauthenticated LDAP configuration handler passes request values directly into a SQL UPDATE via Config::UpdateParameter() without prepared statements, allowing a stacked-query injection that overwrites the &#x27;dot&#x27; configuration parameter (the Graphviz binary path) with an attacker-controlled command. report_network_map.php then passes that value to exec(), resulting in remote code execution as the web server user on Docker deployments that run with REMOTE_USER set to dcim.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-28516

**参考链接**: 
- [参考资料](https://chocapikk.com/posts/2026/opendcim-sqli-to-rce/)
- [参考资料](https://github.com/Chocapikk/opendcim-exploit)
- [参考资料](https://nvd.nist.gov/vuln/detail/CVE-2026-28516)

- **漏洞ID**: `CVE-2026-6664`
- **CVE**: `CVE-2026-6664` (2026)
- **严重程度**: 🟠 HIGH
- **风险等级**: 极高风险 (4.5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.00698 (percentile 0.53713) @ 2026-11-17

**描述**: PgBouncer before 1.25.2 contains an integer overflow in the SCRAM authentication packet parser that bypasses a boundary check, allowing an unauthenticated remote attacker to crash the process with a malformed packet. This template passively identifies the running PgBouncer version over the PostgreSQL wire protocol - the server_version parameter (reported as X.Y.Z/bouncer) returned on the admin database when the pooler accepts unauthenticated connections (auth_type any/trust) - and flags instances older than 1.25.2 without sending the crash payload.

- **预估影响**: 数千个

### Unity Catalog - Unauthenticated API Access

- **漏洞ID**: `unity-catalog-unauth`
- **CVE**: -
- **严重程度**: 🟠 HIGH
- **风险等级**: 高风险 (4/5)
- **影响资产**: 未知
- **预估影响**: 数千个


**描述**: Unity Catalog OSS ships with server.authorization set to disable by default. In this mode the server does not register its authentication decorators, so the Unity Catalog REST API is reachable without a token. An unauthenticated GET /api/2.1/unity-catalog/catalogs returns the catalog listing, and the same access allows reading and changing schemas, tables, volumes, functions and models.
