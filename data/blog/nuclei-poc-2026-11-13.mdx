### FUXA &lt;&#x3D; 1.2.8 - Authentication Bypass to Remote Code Execution

- **漏洞ID**: `CVE-2025-69985`
- **CVE**: `CVE-2025-69985` (2025)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.06021 (percentile 0.93446) @ 2026-11-12

**描述**: FUXA versions up to and including 1.2.8 contain an authentication bypass in the jwt-helper.js middleware. The requireAuth function trusts the HTTP Referer header containing &#x27;/fuxa&#x27; (or localhost/loopback patterns) to whitelist requests as &quot;internal&quot;, skipping JWT verification entirely. This allows unauthenticated attackers to POST to /api/runscript and execute arbitrary Node.js code server-side via Module._compile(), typically running as root inside Docker deployments.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2025-69985

**参考链接**: 
- [参考资料](https://nvd.nist.gov/vuln/detail/CVE-2025-69985)

### Apache bRPC Heap Profiler - Remote Command Injection

- **漏洞ID**: `CVE-2025-60021`
- **CVE**: `CVE-2025-60021` (2025)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: Apache 服务器
- **预估影响**: 数百万台
- **EPSS**: 0.25711 (percentile 0.97994) @ 2026-11-12

**描述**: Apache bRPC versions before 1.15.0 contain a remote command injection vulnerability in the heap profiler built-in service (/pprof/heap). The extra_options query parameter is concatenated directly into a shell command string passed to popen() without any validation or sanitization, allowing unauthenticated attackers to execute arbitrary OS commands on the server. The display parameter must be set to text, svg, or flamegraph to reach the vulnerable code path, and jemalloc profiling must be active (MALLOC_CONF&#x3D;prof:true).


**攻击向量**: 网络扫描

**CVE编号**: CVE-2025-60021

**参考链接**: 
- [参考资料](https://nvd.nist.gov/vuln/detail/CVE-2025-60021)

### MajorDoMo - OS Command Injection via Race Condition

- **漏洞ID**: `CVE-2026-27175`
- **CVE**: `CVE-2026-27175` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.06904 (percentile 0.94173) @ 2026-11-12

**描述**: MajorDoMo (Major Domestic Module) is vulnerable to unauthenticated OS command injection via rc/index.php. The $param variable is interpolated into a command string within double quotes without escapeshellarg() sanitization, and the cycle_execs.php worker executes the queued command via exec() without sanitization. An attacker triggers cycle_execs.php to start the polling worker, then injects a malicious command via the rc endpoint. Detection requires the cycle_execs.php worker to be running, which is the default state for deployed MajorDoMo instances.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-27175

**参考链接**: 
- [参考资料](https://nvd.nist.gov/vuln/detail/CVE-2026-27175)

### Fortinet FortiSandbox - Path Traversal Authentication Bypass

- **漏洞ID**: `CVE-2026-39813`
- **CVE**: `CVE-2026-39813` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.22584 (percentile 0.97743) @ 2026-11-12

**描述**: A path traversal vulnerability (CWE-24) in the FortiSandbox JRPC API is_valid_session() function allows an unauthenticated attacker to bypass authentication. The user-supplied session value is passed to os.path.join() without validation. A session of &quot;../../tmp/&quot; resolves to /tmp/, which always exists and has a recent mtime, so the session check succeeds. This grants unauthenticated access to read-only JRPC methods such as sys/status (version, hostname, serial number, and resource usage). Affects FortiSandbox 4.4.0 through 4.4.8 and 5.0.0 through 5.0.5. Fixed in 4.4.9 and 5.0.6 (FG-IR-26-112). The patched is_valid_session() accepts only 32-character hexadecimal session IDs.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-39813

**参考链接**: 
- [参考资料](https://rustlang.rs/posts/blog_cve_2026_39813_en/)
- [参考资料](https://fortiguard.fortinet.com/psirt/FG-IR-26-112)
- [参考资料](https://www.csa.gov.sg/alerts-and-advisories/alerts/al-2026-038/)
