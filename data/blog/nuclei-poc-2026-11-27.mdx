### Yamcs &lt;&#x3D;5.11.12 - Arbitrary File Read

- **漏洞ID**: `CVE-2026-55552`
- **CVE**: `CVE-2026-55552` (2026)
- **严重程度**: 🟠 HIGH
- **风险等级**: 极高风险 (4.5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.01722 (percentile 0.77943) @ 2026-11-26

**描述**: Yamcs through 5.11.12 serves static web resources through a handler that resolves the requested path against the configured web root without rejecting absolute paths. A request path that begins with a double slash is resolved as an absolute filesystem path, discarding the web root, and the handler returns the referenced file from the underlying host, letting unauthenticated attackers read any non-hidden file readable by the Yamcs service account whose path contains no dot segment.


**攻击向量**: 网络扫描
