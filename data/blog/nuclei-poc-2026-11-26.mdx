### SignalWire FreeSWITCH &lt; 1.11.3 - SIP MESSAGE api-proto OS Command Injection

- **漏洞ID**: `CVE-2026-116779`
- **CVE**: `CVE-2026-116779` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.43693 (percentile 0.99051) @ 2026-11-25

**描述**: SignalWire FreeSWITCH before 1.11.3 is vulnerable to OS command injection via an inbound SIP MESSAGE (CVE-2026-116779). sofia_presence_handle_sip_i_message splits the recipient user on &#x27;+&#x27; and treats the left side as a chat protocol selector; selecting the built-in &quot;api&quot; chat interface passes the remainder to switch_api_execute(), so a recipient of the form api+system &lt;cmd&gt; runs &lt;cmd&gt; as an OS command with the FreeSWITCH process privileges (typically root). The chat path requires the inbound MESSAGE to authenticate, but FreeSWITCH ships well-known default credentials (extension 1000 / password 1234 on stock vanilla) and empty-password users. This template authenticates with those defaults over SIP digest, injects api+system ping &lt;interactsh&gt; (firing an out-of-band callback for real RCE evidence), and keys on the in-band differential: a vulnerable server accepts the api-proto MESSAGE (202 Accepted) and executes it, whereas 1.11.3+ disables the api chat proto by default and returns 403.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-116779
