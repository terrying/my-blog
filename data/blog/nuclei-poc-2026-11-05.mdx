### Laravel TokenGuard - Authentication Bypass

- **漏洞ID**: `CVE-2026-114509`
- **CVE**: `CVE-2026-114509` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.00777 (percentile 0.55961) @ 2026-11-04

**描述**: Laravel&#x27;s TokenGuard (driver &#x3D;&gt; token, hash &#x3D;&gt; false) does not validate the
credential type before the database lookup. Sending a JSON body with
api_token as an array of integers (&#x7B;&quot;api_token&quot;:&#x5B;0&#x5D;&#x7D;) produces a
whereIn(&#x27;api_token&#x27;, &#x5B;0&#x5D;) query; under MySQL/MariaDB implicit casting,
every varchar token not starting with a digit evaluates to 0, so the first
user row is returned to an unauthenticated attacker.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-114509

- **CVE**: `CVE-2026-118539` (2026)

- **风险等级**: 极高风险 (5/5)
- **影响资产**: Drupal 站点
- **预估影响**: 数千个

**描述**: Drupal Commerce Core before 3.3.13 on the 3.x branch and before 8.x-2.41

guest draft order persists. Sites without a usable product among the sampled
IDs produce no finding, which is inconclusive.

### GitLab - SAML Authentication Bypass

- **漏洞ID**: `CVE-2025-25291`
- **CVE**: `CVE-2025-25291` (2025)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: GitLab 平台
- **预估影响**: 数千个
- **EPSS**: 0.20965 (percentile 0.9757) @ 2026-11-04

**描述**: ruby-saml provides security assertion markup language (SAML) single sign-on (SSO) for Ruby. An authentication bypass vulnerability was found in ruby-saml prior to versions 1.12.4 and 1.18.0 due to a parser differential. ReXML and Nokogiri parse XML differently; the parsers can generate entirely different document structures from the same XML input. That allows an attacker to be able to execute a Signature Wrapping attack. This issue may lead to authentication bypass. Versions 1.12.4 and 1.18.0 fix the issue.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2025-25291
