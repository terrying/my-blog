### Copeland/Dixell XWEB EVO - Pre-Auth OS Command Injection via Username

- **漏洞ID**: `CVE-2026-124002`
- **CVE**: `CVE-2026-124002` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.03224 (percentile 0.8849) @ 2026-11-18

**描述**: XWEB EVO versions 5.2.3 through before 5.7.0 contain a pre-authentication OS command injection vulnerability. The login.lua CGI splices the submitted username directly into an io.popen() shell command (via find) before any password check occurs. Injecting shell metacharacters closes the find argument and executes arbitrary OS commands as www-data, escalatable to root via the setuid-root wlua interpreter (CVE-2026-124003). The product is End-of-Software-Support (EOL March 2026) and will not receive patches.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-124002

- **预估影响**: 数千个
- **EPSS**: 0.20965 (percentile 0.97613) @ 2026-11-18

**描述**: ruby-saml provides security assertion markup language (SAML) single sign-on (SSO) for Ruby. An authentication bypass vulnerability was found in ruby-saml prior to versions 1.12.4 and 1.18.0 due to a parser differential.
