### Rclone 1.46.0 - 1.74.2 - Unauthenticated Arbitrary File Read via --rc-serve

- **漏洞ID**: `CVE-2026-49980`
- **CVE**: `CVE-2026-49980` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.00781 (percentile 0.56723) @ 2026-11-19

**描述**: Rclone 1.46.0 through 1.74.2 accepts unauthenticated GET and HEAD requests of the form /&#x5B;remote:path&#x5D;/object when the remote control server runs with --rc-serve and without HTTP authentication. The remote value is taken from the URL and passed to normal backend initialization, so an inline remote such as :local: reads any file on the host, and from 1.55.0 on backend options that run local commands lead to command execution.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-49980

### Copeland/Dixell XWEB EVO - Pre-Auth OS Command Injection via Username

- **漏洞ID**: `CVE-2026-124002`
- **CVE**: `CVE-2026-124002` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.03224 (percentile 0.88507) @ 2026-11-19

**描述**: XWEB EVO versions 5.2.3 through before 5.7.0 contain a pre-authentication OS command injection vulnerability. The login.lua CGI splices the submitted username directly into an io.popen() shell command (via find) before any password check occurs. Injecting shell metacharacters closes the find argument and executes arbitrary OS commands as www-data, escalatable to root via the setuid-root wlua interpreter (CVE-2026-124003). The product is End-of-Software-Support (EOL March 2026) and will not receive patches.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-124002
