- **漏洞ID**: `CVE-2026-109618`
- **CVE**: `CVE-2026-109618` (2026)

- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.05307 (percentile 0.92563) @ 2026-10-22

**描述**: PHP uses longjmp() for out-of-memory (OOM) errors to exit the current context and abort handling of the request. ### WordPress OttoKit Plugin &lt;&#x3D; 1.1.40 - Unauthenticated Privilege Escalation via connection-denied Token

- **漏洞ID**: `CVE-2026-110372`
- **CVE**: `CVE-2026-110372` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: WordPress 站点
- **预估影响**: 数千万个
- **EPSS**: 0.00268 (percentile 0.17958) @ 2026-10-22

**描述**: OttoKit (formerly SureTriggers) WordPress plugin &lt;&#x3D; 1.1.40 unauthenticated privilege escalation. When an admin denies the OttoKit SaaS connection, the plugin stores the fixed public string &#x27;connection-denied&#x27; as the site API secret. The RestController::autheticate_user permission callback reads the &#x27;st_authorization&#x27; request header, strips a &#x27;Bearer &#x27; prefix via sscanf($token,&#x27;Bearer %s&#x27;), then hash_equals() it against the stored secret. An attacker who sends &#x27;st-authorization: Bearer connection-denied&#x27; is authenticated to the automation REST API and can create administrator accounts. Fixed in 1.1.41.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-110372

**参考链接**: 
- [参考资料](https://patchstack.com/database/wordpress/plugin/suretriggers/vulnerability/wordpress-ottokit-plugin-1-1-40-privilege-escalation-vulnerability)
