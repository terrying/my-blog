### GeoServer Service Security Bypass via Prefixed Service Name (x/WFS)

- **漏洞ID**: `CVE-2026-129243`
- **CVE**: `CVE-2026-129243` (2026)
- **严重程度**: 🟠 HIGH
- **风险等级**: 极高风险 (4.5/5)
- **影响资产**: 未知
- **预估影响**: 数千个


**描述**: A mismatch exists between service dispatch and service-security rule matching in GeoServer. When a request uses a specially prefixed service name (such as x/WFS), the dispatcher strips the prefix (x/) and routes the operation, while service security continues matching rules against the unstripped x/WFS string. This allows an attacker to invoke restricted operations while evading service-level security rules intended for the standard service name. Under default rules, anonymous users can reach WFS stored-query creation and deletion operations, though layer and data-security rules remain enforced.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-129243
