### OpenObserve &lt;&#x3D; 0.90.2 - Unauthenticated Runtime Configuration Disclosure

- **漏洞ID**: `CVE-2026-63645`
- **CVE**: `CVE-2026-63645` (2026)
- **严重程度**: 🟠 HIGH
- **风险等级**: 极高风险 (4.5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.00333 (percentile 0.26889) @ 2026-11-15

**描述**: OpenObserve 0.90.2 and earlier exposes the /config/runtime endpoint without authentication. The endpoint serializes the complete server configuration, and its redaction only covers keys that contain words such as password, secret, key, auth or token. Fields such as meta_postgres_dsn, meta_postgres_ro_dsn and the root user email are returned in clear text, so a PostgreSQL metadata store connection string with its password is disclosed to anyone who can reach the server.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-63645

**参考链接**: 
- [参考资料](https://github.com/openobserve/openobserve/security/advisories/GHSA-v496-g5c9-vqxw)

- [参考资料](https://nvd.nist.gov/vuln/detail/CVE-2026-63645)
