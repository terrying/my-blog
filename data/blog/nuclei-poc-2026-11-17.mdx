### DirectoryPress &lt;&#x3D; 3.6.27 - Unauthenticated Local File Inclusion

- **漏洞ID**: `CVE-2026-62032`
- **CVE**: `CVE-2026-62032` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: WordPress 站点
- **预估影响**: 数千万个
- **EPSS**: 0.00404 (percentile 0.35229) @ 2026-11-16

**描述**: The DirectoryPress plugin for WordPress is vulnerable to Local File Inclusion in all versions up to, and including, 3.6.27. The directorypress_listings_handler class merges user-supplied GET parameters into shortcode attributes when include_get_params is enabled (default). The template parameter is passed unsanitized through directorypress_display_template() into directorypress_has_template(), which checks is_file() on the raw user input and includes it directly via PHP include(). This makes it possible for unauthenticated attackers to include and execute arbitrary files on the server, allowing the execution of any PHP code in those files. Exploitation requires a page with a DirectoryPress shortcode to exist.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-62032

**参考链接**: 
- [参考资料](https://nvd.nist.gov/vuln/detail/CVE-2026-62032)
- [参考资料](https://patchstack.com/database/wordpress/plugin/directorypress/vulnerability/wordpress-directorypress-plugin-3-6-27-local-file-inclusion-vulnerability)
- [参考资料](https://wordpress.org/plugins/directorypress/)
