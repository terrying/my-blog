### Laravel TokenGuard - Authentication Bypass

- **漏洞ID**: `CVE-2026-114509`
- **CVE**: `CVE-2026-114509` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.00777 (percentile 0.55892) @ 2026-11-03

**描述**: Laravel&#x27;s TokenGuard (driver &#x3D;&gt; token, hash &#x3D;&gt; false) does not validate the
credential type before the database lookup. Sending a JSON body with
api_token as an array of integers (&#x7B;&quot;api_token&quot;:&#x5B;0&#x5D;&#x7D;) produces a
whereIn(&#x27;api_token&#x27;, &#x5B;0&#x5D;) query; under MySQL/MariaDB implicit casting,
every varchar token not starting with a digit evaluates to 0, so the first
user row is returned to an unauthenticated attacker.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-114509
