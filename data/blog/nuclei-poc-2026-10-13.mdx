### Gotenberg &lt; 8.31.0 - Server-Side Request Forgery

- **漏洞ID**: `CVE-2026-42596`
- **CVE**: `CVE-2026-42596` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.01773 (percentile 0.77576) @ 2026-10-12

**描述**: Gotenberg before 8.31.0 is vulnerable to server-side request forgery (SSRF) due to insufficient validation of URLs in the downloadFrom API. An unauthenticated attacker can exploit the flaw by providing specially crafted IPv4-mapped IPv6 addresses (such as http://&#x5B;::ffff:127.0.0.1&#x5D;) that bypass the deny-list and allow access to internal resources. Fixed versions properly recognize these addresses and prevent such requests.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-42596

### GravitLauncher LaunchServer &lt;&#x3D;5.7.11 - Unauthenticated Path Traversal to Arbitrary File Read

- **漏洞ID**: `CVE-2026-54617`
- **CVE**: `CVE-2026-54617` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.00677 (percentile 0.50933) @ 2026-10-12

**描述**: LaunchServer&#x27;s Netty FileServerHandler computes the served path by stripping one leading character on the assumption that every request-target begins with &#x27;/&#x27;. Netty&#x27;s HttpServerCodec accepts a request-target without a leading slash verbatim, so a request without a leading slash bypasses path normalization and escapes the updatesDir. The file server is enabled by default (netty.fileServerEnabled&#x3D;true) on 0.0.0.0:9274 with no authentication, allowing an unauthenticated remote GET to read any file readable by the LaunchServer process including its own ECDSA signing key (.keys/ecdsa_id), which signs access JWTs and enables full authentication bypass for any account.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-54617

**参考链接**: 
- [参考资料](https://github.com/GravitLauncher/Launcher/security/advisories/GHSA-5g75-477j-2c2f)
- [参考资料](https://github.com/GravitLauncher/Launcher/commit/1e0b3a3)
