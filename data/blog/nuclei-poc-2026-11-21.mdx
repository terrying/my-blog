### GitLab - SAML Authentication Bypass

- **漏洞ID**: `CVE-2025-25291`
- **CVE**: `CVE-2025-25291` (2025)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: GitLab 平台
- **预估影响**: 数千个
- **EPSS**: 0.3359 (percentile 0.98422) @ 2026-11-20

**描述**: ruby-saml provides security assertion markup language (SAML) single sign-on (SSO) for Ruby. An authentication bypass vulnerability was found in ruby-saml prior to versions 1.12.4 and 1.18.0 due to a parser differential. ReXML and Nokogiri parse XML differently; the parsers can generate entirely different document structures from the same XML input. That allows an attacker to be able to execute a Signature Wrapping attack. This issue may lead to authentication bypass. Versions 1.12.4 and 1.18.0 fix the issue.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2025-25291

**参考链接**: 
- [参考资料](https://portswigger.net/research/saml-roulette-the-hacker-always-wins)

### GeoNetwork - Pre-Auth Formatter Upload (Missing Authorization)

- **漏洞ID**: `CVE-2026-63219`
- **CVE**: `CVE-2026-63219` (2026)
- **严重程度**: 🟠 HIGH
- **风险等级**: 极高风险 (4.5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.01359 (percentile 0.72372) @ 2026-11-20

**描述**: GeoNetwork before 4.4.12 and before 4.2.17 is missing the @PreAuthorize(&quot;hasAuthority(&#x27;UserAdmin&#x27;)&quot;) authorization check on the formatter upload API (addFormatter in FormatterAdminApi, POST /srv/api/formatters), a missing authorization vulnerability (CWE-862). A remote unauthenticated attacker can upload arbitrary .xsl/.zip formatter files to the server storage, which combined with unsafe XSLT execution (CVE-2026-58400) enables unauthenticated remote code execution. This template proves the authorization bypass: an unauthenticated multipart upload of a benign XSL formatter is accepted by the server (HTTP 201 Created) instead of being rejected with 401/403.

**CVE编号**: CVE-2026-63219

**描述**: GeoNetwork before 4.4.12 and before 4.2.17 is missing the @PreAuthorize(&quot;hasAuthority(&#x27;UserAdmin&#x27;)&quot;) authorization check on the formatter upload API (addFormatter in FormatterAdminApi, POST /srv/api/formatters), a missing authorization vulnerability (CWE-862).
