### Theme My Login &lt;&#x3D; 7.2.1 - Privilege Escalation

- **漏洞ID**: `CVE-2026-89079`
- **CVE**: `CVE-2026-89079` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: WordPress 站点
- **预估影响**: 数千万个
- **EPSS**: 0.00294 (percentile 0.20851) @ 2026-10-23

**描述**: Theme My Login (TML) &lt;&#x3D; 7.2.1 for WordPress is vulnerable to unauthenticated account takeover on multisite installations. The multisite-only filter tml_ms_filter_pre_insert_user_data(), hooked on wp_pre_insert_user_data, hashes and injects $_POST&#x5B;&#x27;user_pass1&#x27;&#x5D; into the user record whenever the tml_user_passwords network option is enabled, WITHOUT checking the $update flag. During a lost password request (wp-login.php?action&#x3D;lostpassword -&gt; retrieve_password() -&gt; wp_update_user()), this filter fires on the EXISTING target user, overwriting their password with an attacker-chosen value. An unauthenticated attacker can therefore take over any account, including a network administrator, by sending user_pass1 in the lost-password POST. Fixed in 7.2.2 (changeset 3696081 / commit 06b76231) by adding the $update guard and only applying the password during activation.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-89079

- [参考资料](https://patchstack.com/database/wordpress/plugin/theme-my-login/vulnerability/wordpress-theme-my-login-plugin-7-2-1-unauthenticated-privilege-escalation-vulnerability)
