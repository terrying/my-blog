### Advance Product Search &lt;&#x3D; 1.4.4 - Unauthenticated Time-Based Blind SQL Injection

- **漏洞ID**: `CVE-2026-56070`
- **CVE**: `CVE-2026-56070` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: WordPress 站点
- **预估影响**: 数千万个

### MountDev AI MCP Connector &lt;&#x3D; 1.6.1 - Unauthenticated Admin OAuth Token Exposure

- **漏洞ID**: `CVE-2026-15015`
- **CVE**: `CVE-2026-15015` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: WordPress 站点
- **预估影响**: 数千万个
- **EPSS**: 0.00712 (percentile 0.52779) @ 2026-10-20

**描述**: MountDev AI MCP Connector for WordPress (mountdev-ai-mcp-connector) &lt;&#x3D; 1.6.1 is vulnerable to unauthenticated authorization bypass (CWE-862) via its OAuth 2.0 implementation. The plugin exposes a publicly accessible Dynamic Client Registration endpoint (/mcp-register) at WordPress init-level that allows any unauthenticated caller to register arbitrary OAuth clients. The subsequent authorization endpoint (/wp-json/mountdev-ai-mcp-connector/v1/oauth/authorize) then auto-approves the OAuth flow using the first WordPress administrator account found via get_users(&#x7B;role: administrator, number: 1&#x7D;), issuing an admin-bound authorization code without checking who is making the request. Exchanging this code at /mcp-token yields a full Bearer token granting administrator-equivalent access to the MCP tool surface and all exposed WordPress content, users, options, and settings.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-15015

**参考链接**: 
- [参考资料](https://github.com/les-k/wp-secure-mcp)
- [参考资料](https://plugins.trac.wordpress.org/browser/mountdev-ai-mcp-connector/tags/1.6.0/includes/class-oauth-controller.php#L370)
- [参考资料](https://nvd.nist.gov/vuln/detail/CVE-2026-15015)
- [参考资料](https://www.rapid7.com/db/vulnerabilities/cve-2026-15015/)

- **CVE**: `CVE-2026-72867` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: 未知

- **EPSS**: 0.00954 (percentile 0.60773) @ 2026-10-20

**描述**: Dokploy &lt;&#x3D; 0.29.12 is vulnerable to authenticated OS command injection through the customGitBranch field of a compose service.
