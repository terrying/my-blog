### MLflow Tracking Server - Unauthenticated Model Source Path Traversal RCE

- **漏洞ID**: `CVE-2025-11201`
- **CVE**: `CVE-2025-11201` (2025)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.26282 (percentile 0.98016) @ 2026-11-10

**描述**: MLflow Tracking Server is vulnerable to an unauthenticated path traversal in the model-version creation API. The server validates the `source` parameter and rejects relative/local paths, but skips that validation entirely when the request carries the `mlflow.prompt.is_prompt` tag (the request is then treated as a prompt). An unauthenticated attacker can supply an arbitrary traversal path as the model version `source`, writing attacker-controlled files to arbitrary locations on the server filesystem and achieving remote code execution under the service account. The fix adds an opt-in MLFLOW_CREATE_MODEL_VERSION_SOURCE_VALIDATION_REGEX allowlist; with the default (unset) configuration the bypass remains exploitable even on 2.22.4.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2025-11201

**参考链接**: 
- [参考资料](https://nvd.nist.gov/vuln/detail/CVE-2025-11201)
- [参考资料](https://www.zerodayinitiative.com/advisories/ZDI-25-931/)

### HT Contact Form Widget for Elementor &lt;&#x3D; 2.2.1 - Unauthenticated Arbitrary File Upload

- **漏洞ID**: `CVE-2025-7340`
- **CVE**: `CVE-2025-7340` (2025)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: WordPress 站点
- **预估影响**: 数千万个
- **EPSS**: 0.01751 (percentile 0.7806) @ 2026-11-10

**描述**: The HT Contact Form Widget For Elementor Page Builder & Gutenberg Blocks & Form Builder plugin for WordPress is vulnerable to arbitrary file upload in all versions up to and including 2.2.1 due to missing file type validation in the temp_file_upload() function. The handler is registered on the wp_ajax_nopriv_ht_form_temp_file_upload action, so an unauthenticated attacker holding a form nonce (exposed on any page rendering the &#x5B;ht_form&#x5D; widget) can upload a PHP file to wp-content/uploads/ht_form/temp/ and execute it, achieving remote code execution.


**攻击向量**: 网络扫描

- **CVE**: `CVE-2026-116747` (2026)

- **风险等级**: 极高风险 (5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.00623 (percentile 0.50207) @ 2026-11-10

**描述**: Kener 3.0.0 before 4.1.10 falls back to the hardcoded JWT secret &quot;DUMMY_SECRET&quot; when the KENER_SECRET_KEY environment variable is unset or empty. An unauthenticated attacker can forge session cookies and password-reset tokens signed with that key. A forged password-reset token accepted by POST /account/forgot/api/password-reset produces a distinct response: the request passes token verification and fails only later at user lookup (&quot;User does not exist&quot;), whereas patched versions reject the token signature immediately with &quot;Invalid or expired token&quot;.
