### Podlove Podcast Publisher &lt;&#x3D; 4.5.1 - Arbitrary File Upload

- **漏洞ID**: `CVE-2026-13001`
- **CVE**: `CVE-2026-13001` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: WordPress 站点
- **预估影响**: 数千万个
- **EPSS**: 0.00828 (percentile 0.54489) @ 2026-08-18

**描述**: Podlove Podcast Publisher plugin for WordPress through 4.5.1 is vulnerable to arbitrary file uploads due to missing file type validation in the podlove_handle_cache_files function. The image cache derives the stored file extension from the path of the attacker supplied source URL, while the image validation is performed against a different file name taken from the full source URL, so a source URL whose path carries a dangerous extension is written to the cache with that extension.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-13001

**参考链接**: 
- [参考资料](https://github.com/podlove/podlove-publisher/commit/5b32468601e903bae2bcacfaf36ff583d2bc9387)
- [参考资料](https://www.wordfence.com/threat-intel/vulnerabilities/id/f81a3429-f378-4295-adbe-ad6f1df59701?source=cve)
- [参考资料](https://github.com/advisories/GHSA-7gcx-p8g5-3g9x)
- [参考资料](https://plugins.trac.wordpress.org/changeset/3597461/podlove-podcasting-plugin-for-wordpress)
