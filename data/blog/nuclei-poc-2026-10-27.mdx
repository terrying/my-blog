### Ruoyi-Vue-Pro - Unauthenticated Admin Takeover via Predictable SMS Code

- **漏洞ID**: `CVE-2026-116006`
- **CVE**: `CVE-2026-116006` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.00384 (percentile 0.3219) @ 2026-10-26

**描述**: ruoyi-vue-pro (Yudao) ships base configuration yudao.sms-code.begin-code&#x3D;end-code&#x3D;9999, so every generated SMS verification code is the constant &quot;9999&quot; in all profiles. The anonymous SMS-login flow therefore grants an access token to any account whose mobile number is known: send-sms-code followed by sms-login with code 9999 issues a full token, including for the seeded super administrator account (mobile 18818260272 in the shipped SQL). No CAPTCHA hook exists for scene&#x3D;21 in any profile.

### Rejetto HTTP File Server 2.4.x - Template Injection

- **漏洞ID**: `CVE-2026-97359`
- **CVE**: `CVE-2026-97359` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: 未知
- **预估影响**: 数千个
- **EPSS**: 0.01411 (percentile 0.72481) @ 2026-10-26

**描述**: Rejetto HTTP File Server (HFS) 2.4.x inserts the multipart upload filename into the server-side template symbol map as %item-resource% without escaping. A filename containing the literal %item-resource% is substituted a second time by the sequential global replacement in xtpl(), allowing a :&#x7D; sequence to terminate the quoting region so a following &#x7B;.exec|...&#x7D; macro is executed as an operating-system command. An unauthenticated attacker achieves remote code execution with a single request.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-97359

**参考链接**:

### NEX-Forms Express WP Form Builder &lt; 9.2.3 - Unauthenticated Stored XSS

- **漏洞ID**: `CVE-2026-10525`
- **CVE**: `CVE-2026-10525` (2026)
- **严重程度**: 🟠 HIGH
- **风险等级**: 极高风险 (4.5/5)
- **影响资产**: WordPress 站点
- **预估影响**: 数千万个
- **EPSS**: 0.00275 (percentile 0.19769) @ 2026-10-26

**描述**: NEX-Forms Express WP Form Builder plugin for WordPress before 9.2.3 is vulnerable to unauthenticated stored Cross-Site Scripting. The plugin registers a wp_ajax_nopriv_submit_nex_form handler for form submissions. Array-type field values are processed through rest_sanitize_array(), which only reindexes the array and performs no HTML sanitization, so markup is stored verbatim. When an administrator views the submitted entries, the stored payload renders without esc_html() escaping and executes arbitrary JavaScript in the admin&#x27;s browser. Scalar fields are not affected (they are passed through strip_tags()).


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-10525

**参考链接**: 
- [参考资料](https://nvd.nist.gov/vuln/detail/CVE-2026-10525)
- [参考资料](https://wpscan.com/vulnerability/d1e191e6-ff5b-4cb8-9b12-8ae73cf0d2f0/)
