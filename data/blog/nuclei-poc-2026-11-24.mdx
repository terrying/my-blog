### Apache Roller - XML-RPC Pre-Auth Deserialization RCE

- **漏洞ID**: `CVE-2026-129448`
- **CVE**: `CVE-2026-129448` (2026)
- **严重程度**: 🔴 CRITICAL
- **风险等级**: 极高风险 (5/5)
- **影响资产**: Apache 服务器
- **预估影响**: 数百万台
- **EPSS**: 0.05459 (percentile 0.9294) @ 2026-11-23

**描述**: Deserialization of Untrusted Data in Apache Roller versions 4.0.0 through 6.1.4 allows an unauthenticated remote attacker to execute arbitrary code. The XML-RPC endpoint accepts vendor extension types and deserializes them before authenticating the requester. This is the same vulnerability as CVE-2026-82384, which listed only Apache Roller 6.1.5 as affected. This issue is being actively exploited. Users are recommended to upgrade to Apache Roller 6.1.6 or later, which disables the extension types and rejects XML-RPC requests when the XML-RPC feature is disabled. Users who cannot upgrade right away should set &quot;enabledForExtensions&quot; to &quot;false&quot; in WEB-INF/web.xml, or remove the &quot;/roller-services/xmlrpc&quot; servlet mapping, and restart Roller. Disabling XML-RPC in the administration UI is not enough, because older versions deserialize the request before checking that setting.


**攻击向量**: 网络扫描

**CVE编号**: CVE-2026-129448

**参考链接**: 
- [参考资料](https://roller.apache.org/security.html)
- [参考资料](https://github.com/apache/roller/pull/171)

- **严重程度**: 🔴 CRITICAL

- **EPSS**: 0.3359 (percentile 0.98423) @ 2026-11-23
